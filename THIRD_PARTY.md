# Third-party software and model weights

PTK's MIT licence covers PTK code. It does not replace dependencies' licences or establish rights in downloaded media and pretrained model weights.

## Model licence remains unresolved

The maintained [Demucs licence note](https://github.com/adefossez/demucs#license) distinguishes MIT-licensed code from pretrained weights. The maintainer explicitly states that the weights' licence is unclear because some training data were research-only and that they cannot grant the needed rights. PTK uses the pretrained `htdemucs` model; it does not train or bundle weights.

Do not represent commercial use or redistribution of these weights as cleared. A commercial or bundled release needs clarification from the relevant rights holders or a replacement model with suitable, explicit terms. Downloading a checkpoint successfully is not evidence of a licence grant. This issue is still open.

## Dependency review

The locked reference sets identify exact package versions. The installed-package licence inventory generated by `tools/license_inventory.py` records each distribution's declared licence, source URL and packaged licence-file locations. It is evidence for review, not automatic approval of every downstream obligation.

Notable points from the Apple Silicon reference environment:

| Component | Declared terms / review point |
| --- | --- |
| Demucs 4.1.0 code | MIT; weights are a separate unresolved issue above. |
| PyTorch 2.11.0 | BSD-3-Clause; bundled components have additional notices. |
| torchaudio 2.11.0 | Licence metadata is missing; inspect its upstream [licence](https://github.com/pytorch/audio/blob/main/LICENSE). |
| TorchCodec 0.11.1 | BSD 3-Clause declaration. |
| yt-dlp 2026.11.23 | Unlicense declaration; its dependencies have separate terms. |
| librosa 0.11.0 | ISC declaration. |
| SoundFile 0.12.1 | BSD 3-Clause declaration; libsndfile has separate terms. |
| NumPy 2.4.6 | Multiple declared licences, including BSD-3-Clause, MIT, 0BSD, Zlib and CC0. |
| ffmpeg-python 0.2.0 | Metadata says UNKNOWN; review the upstream [licence](https://github.com/kkroening/ffmpeg-python/blob/master/LICENSE). |
| lameenc 1.9.0 | LGPL-3.0-or-later declaration; important if bundling binaries. |
| FFmpeg executable | Not part of the PTK wheel. Terms depend on build configuration; see [FFmpeg legal information](https://ffmpeg.org/legal.html). |

Windows/Linux reference versions may differ. Before bundling an installer, review the inventory for that exact environment and ship the required notices/licence files and any corresponding source or relinking material. A standalone installer, model redistribution, media rights and signed application distribution have not been cleared by this review.
